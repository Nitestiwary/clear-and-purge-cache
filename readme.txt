Professional caching, minification, and database optimization engine to scale site speeds. Unlocks premium performance features for free.

== Description ==
Developed by Monetiscope, Clear and Purge Cache is an all-in-one optimization suite engineered to instantly lower page load times, lower database overhead, and clean up asset arrays. 

This plugin incorporates advanced page-caching configurations, complete script/stylesheet minification engines, dynamic lazy loading, and deep database scrubbing tools into an entirely unrestricted, 100% free package compatible with the latest WordPress 7.0 environments.

== Installation ==
1. Upload the plugin folder to the `/wp-content/plugins/` directory.
2. Activate the plugin through the 'Plugins' menu in WordPress.
3. Navigate to the 'Clear Cache' admin screen to customize deployment controls.

== Features ==
* 100% Free Core and Premium Optimizations.
* Real-time selective caching controlled from the global WordPress Admin Header Bar.
* Complete CSS, JavaScript, and HTML minification + combining engines.
* Asynchronous resource deferrals for render-blocking scripts and external fonts.
* Native, automated Image Optimization and database structural asset purging loops.
